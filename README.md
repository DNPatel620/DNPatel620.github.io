# Dhruv N Patel — Portfolio

A personal portfolio for Dhruv N Patel, a Mechanical Engineering Technology student at the New Jersey Institute of Technology (NJIT). The site introduces Dhruv and brings together his background, projects, skills, and contact information.

## Live website

Visit [dnpatel620.github.io](https://dnpatel620.github.io/).

## View locally

The site is static and has no build step or dependencies. You can open `index.html` directly in a web browser. To preview it through a local web server instead, run this command from the repository directory:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000). Stop the server with `Ctrl+C` when you are done.

## Site pages

- `index.html` — Home
- `about.html` — About Dhruv
- `projects.html` — Projects
- `skills.html` — Skills
- `contact.html` — Contact

Shared styles and interactions are in `style.css` and `script.js`; local media is in `assets/`.
